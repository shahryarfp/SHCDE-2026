How to save and publish your page
  1. Choose a match, add its information, and click Save changes. You can edit other matches after saving.
  2. Click Download updated HTML. Your saved match details and rules are included inside the file.
  3. Open the downloaded file in a browser. To share a website link, upload it as index.html to a GitHub repository and enable GitHub Pages.
  4. To update the public page later, replace its index.html with your newly downloaded file. Visitors see the changes after publication.

The editor is available to everyone with a copy. It changes their local copy only; it does not give them access to your GitHub repository. YouTube playback requires an internet connection and an embeddable video. An “Open on YouTube” link is provided as a fallback.

Your original file stays unchanged until you download a new one.
